# EchoLoom — 当前定位与后续计划

更新：2026-11-06。依据用户新 PRD 重新调整，默认英文。当前主体验是 **Scene Rehearsal：让自己的两位角色先把故事演出来**。

**Let your characters play it out.**

为卡在人物反应、对白和局部场景的创作者，提供一个可介入、可比较、可继续的两人排练舞台。先选两个人，再给一个局面；不要求先建项目、完成头像、普通聊天或填写全部设定。

## 当前体验

1. 我的排戏 → 选两位角色（可快速创建，无需头像）→ 设置开场。
2. 分段演出 → 导演指令／事件／接管 → 改台词或从关键位置重演。
3. 探索两种走向，保存原版本，切换比较。
4. 回顾完整正文 → 确认本场结果 → 复制／TXT／Markdown。
5. 从固定的已认可结果接下一场；上一场后续改动不静默重写它。

星夜剧场的深靛色、暮光、香槟金、衬线标题用于新的 `/rehearsal`；舞台保持纯净阅读面。默认英文，可选中文。旧 `/creator` 与 `/characters` 继续保留。

## 接下来优先做什么

| 顺序 | 工作 | 验证依据 |
| --- | --- | --- |
| 1 | 真实模型端到端与固定场景集评审 | 信息差、对立目标、克制和解、人物底线、接管、锁定文字和跨场景知识；记录真实时延、失败率和费用 |
| 2 | 手机真机可用性 | iOS/Android 软键盘、返回、200% 字号、读屏和导出；视口测试不能替代真机 |
| 3 | 5 位目标作者试用 | 能否创建、介入、探索、切换、认可、导出、接下一场；是否真正采用对白或转折 |
| 4 | 根据错误改进语义约束与上下文 | 优先解决无依据的全知、人物声音趋同和设定冲突；不宣称结构校验代表叙事质量 |
| 5 | 进一步流式适配与长场编辑 | 当前取得结构化片段后按完整块提交；真实供应商支持成熟后，接入更早的语义块流、局部状态提取及更丰富的场景地图 |

当前使用服务端操作记录与按场景去重的计数，不上传原始创作文本到通用分析系统；尚未收集真实七日留存基线，不编造成功率。没有公共市场、多人协作、语音演出、复杂心理参数或大规模搜索。
