## 真实模型验收：待执行

此云环境没有绑定模型密钥。没有发起付费请求，也没有把测试替身输出宣称为真实生成。使用本机已有 `.env`，按以下清单记录结果（不要提交密钥或私人剧情）：

1. 一次创建输入明确外貌、欲望与秘密的原创人物，检查档案和自动头像。
2. 编辑头像、选择历史版本；模拟图像失败后单独重试。
3. 创建第二角色，Direct the cast 自由推演 5–10 个片段；检查声音、动机和秘密知情范围。
4. Play a role 写自己的台词，确认 AI 只回应、不代写用户；输入英文，检查英文输出。
5. 保存、分叉、改写旧片段、下一场戏、恢复保存点；比较原稿与新稿。
6. 模拟断网和超时后恢复；记录文本、图像、编辑分别的耗时、模型 ID 和 API 用量／费用。
7. Windows 更新及真手机输入、关闭弹窗、下载和导入测试。

后续 5 位目标创作者测试方案见 [PRD 第 19 节](creator-mobile-mvp-prd.md)。当前未做用户研究，不报告可用性成功率。

## 已知实现边界

这是移动优先的本地 Web 原型，非云同步产品、原生 App 或多人协作系统。生成以短片段为单位，不做流式展示。事实主要由作者确认，长篇上下文有预算裁剪。叙事导出是已有正文的格式整理。场景列表支持阅读与从该处另开路线，尚不支持拖拽重排。后端请求记录、模型日志用于恢复与诊断；PRD 的完整产品事件看板尚未实现。具体大小限制和数据备份见 [使用指南](creator-mvp.md)。
