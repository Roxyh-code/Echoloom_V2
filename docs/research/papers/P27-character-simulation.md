## 我们应该带着什么问题读

最先区分两项任务：给一个人物模型，让它作出表现；给人物的多份材料，推断一个模型。EchoLoom 当前主要做后一项。因此，这篇首先帮助我们确定下游需要什么信息，不足以直接决定上游怎样抽取、证明和整合这些信息。

可以把我们的目标暂时写成：

```text
来源材料 → 可核对的观察 → 待审核的解释 → 人物模型
                                           ↓
                                  在新情境中检查表现
```

这个图是 EchoLoom 的研究假设，不是论文提出的抽取流程。

## 对 Schema 的初步分析（尚未采用）

| 我们的候选概念 | 为什么需要单独表达 | 接下来如何验证 |
| --- | --- | --- |
| 人物核心特质 | “这个人通常怎样”不应被一次回应直接覆盖 | 用同一人物在不同情境中的反例检查 |
| 当下目标 | 一个人可以为不同事件追求不同目标 | 检查与价值观冲突时能否保留两种解释 |
| 情绪／身体状态 | 疲劳、悲伤等短期条件可能解释一次行为 | 对比去掉状态前后的人工判断 |
| 人物知识边界 | 读者知道的事实不一定属于人物已知信息 | 设计提前透露未来事件的陷阱 |
| 故事时间与叙述位置 | 资料排列顺序可能包含倒叙或回忆 | 交换段落顺序，检查解释是否不合理地改变 |
| 原文依据与解释 | 合理的人物表现仍可能来自无依据的推断 | 每条解释关联支持事例与替代解释 |

这些概念的组合、字段名称和验证方式由我们提出；正式设计须与 CHIRON、PersoNet 等比较。

## 原创演练：一句话不能直接推出稳定人格

设定一个原创角色“林澈”。材料 A 写她在凌晨拒绝陪同事聊天；材料 B 写她当晚刚完成连续抢修；材料 C 写她周末主动组织朋友聚会。

如果只读 A，系统可能把她描述为“冷漠、排斥社交”。我们需要保留的首先是拒绝行为与当时情境；B 提供临时状态的替代解释，C 则让稳定特质的概括更不确定。当前合理输出是“此事不足以确定其稳定社交倾向”，而不是把三个来源平均成一个外向性分数。

这是我们用于检查设计的虚构例子，不是论文材料，也不是已经完成的实验。
